Learning Tracker is an iOS app designed to help users build consistent learning habits by setting personalized goals, tracking daily progress, and celebrating achievements.
With an interactive calendar, streak tracking, and flexible learning durations, the app makes it easier to stay motivated and work toward long-term learning goals.

## Main Features

- **Personalized Learning Goals:** Set a learning goal and choose a duration (week, month, or year).
- **Daily Progress Tracking:** Log daily learning activities and track your progress.
- **Freeze Days:** Use available freeze days when taking a break from learning.
- **Streak Tracking:** Monitor your learning consistency.
- **Interactive Calendar:** View learned and frozen days.
- **Achievements:** Unlock achievements based on your learning progress.
- **Goal Management:** Edit your goal and start a new learning journey.
